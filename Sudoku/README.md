# Sudoku Projects

This repository contains two interactive Sudoku games built with **HTML**, **CSS**, and **JavaScript**.
One for a **4×4 grid** and another for a **9×9 grid**.

---

```
sudoku/
├── 4x4/       
│   ├── index.html
│   ├── style.css
│   ├── script.js
│   └── README.md
├── 9x9/  
│   ├── index.html
│   ├── style.css
│   ├── script.js
│   └── README.md
```

---

## Overview

Each version offers a different level of complexity:
- **4×4 Sudoku** — beginner-friendly, quick to play, includes a success animation when solved.
- **9×9 Sudoku** — classic full-size puzzle with **Easy**, **Medium**, and **Hard** difficulty modes, random clue generation, and a polished UI.

---

## Features

- Dynamic puzzle generation with random clues  
- Difficulty toggle and restart button  
- Keyboard and button input support  
- Visual feedback for wrong entries  
- Success animation using palette colors  
- Responsive design for all screen sizes  

---

## How to Run

1. Open the desired folder (`4x4` or `9x9`).
2. Launch `index.html` in your browser.
